Integración de Cloudinary

Esta guía detalla cómo permitir que los usuarios suban imágenes directamente a la nube desde el navegador utilizando JavaScript Vanilla y Fetch API.

1 Configuración de Cloudinary

  1. Accede a tu consola de Cloudinary.
  2. Obtén tu Cloud Name desde el Dashboard principal.
  3. Ve a Settings > Upload y crea un Upload Preset.
  4. Cambia el modo de firmado a Unsigned. Esto permite subir imágenes sin un API Secret (ideal para frontend).

2 Implementación Técnica

Estructura (HTML)
<!-- Input invisible para capturar el archivo -->
<input type="file" id="fileInput" accept="image/*" style="display:none">

<!-- Zona de interacción -->
<div id="dropZone">
    <p>Haz clic para seleccionar imagen</p>
    <img id="preview" src="" style="display:none; width: 200px">
</div>

<!-- Botón de acción -->
<button id="btnUpload" disabled>Subir a Cloudinary</button>

Lógica (JavaScript)
// Configuración
const CLOUD_NAME = "tu_cloud_name";
const PRESET = "tu_unsigned_preset";

const btnUpload = document.querySelector('#btnUpload');
const fileInput = document.querySelector('#fileInput');

btnUpload.addEventListener('click', () => {
    const file = fileInput.files[0];
    
    // Preparar el cuerpo de la petición (FormData)
    const formData = new FormData();
    formData.append('file', file);
    formData.append('upload_preset', PRESET);

    // Iniciar petición Fetch
    fetch(`https://api.cloudinary.com/v1_1/${CLOUD_NAME}/image/upload`, {
        method: 'POST',
        body: formData
    })
    .then(response => {
        if (!response.ok) throw new Error("Fallo en la comunicación");
        return response.json(); // Convertir respuesta a JSON
    })
    .then(data => {
        // 'data.secure_url' contiene la URL final de la imagen
        console.log("Imagen subida con éxito:", data.secure_url);
        alert("¡Subida exitosa!");
    })
    .catch(error => {
        // Capturar errores de red o de proceso
        console.error("Error detectado:", error);
    });
});

Sección Bonus: Nivel Avanzado

El Widget de Cloudinary

Cloudinary ofrece una interfaz completa (Upload Widget) que ya incluye cámara, filtros y múltiples fuentes. Se usa importando su script oficial y ejecutando cloudinary.openUploadWidget().

Subida desde Backend

En una arquitectura robusta, el Frontend envía la imagen a un servidor (Node.js/Python). El servidor valida al usuario y usa el API Secret para una subida firmada (Signed Upload), garantizando máxima seguridad.
