# Aplicación web: Tipos de Datos Abstractos en Java

## Ejecución

Abra `index.html` en cualquier navegador moderno. No necesita instalar dependencias ni ejecutar un servidor.

## Funciones

- Navegación por fases de la clase.
- Cronómetro de 120 minutos.
- Progreso persistente mediante localStorage.
- Active Recall.
- Explicación Feynman.
- Clasificación entre especificación e implementación.
- Construcción incremental de la clase Fraccion.
- Calculadora exacta de fracciones.
- Ejercicio guiado para implementar sumar.
- Actividad de depuración.
- Reto de transferencia.
- Lista de cotejo.
- Ticket de salida.
- Guía docente protegida con el código `TDA2026`.
