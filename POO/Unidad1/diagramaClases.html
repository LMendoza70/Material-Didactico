De la Idea al Código con UML

Una experiencia interactiva diseñada para dominar la transición entre el lenguaje natural, el modelado visual y la programación en C#.

El Laboratorio de Narrativa

El primer paso para cualquier sistema de software es identificar qué estamos tratando de modelar. En este ejercicio, analizaremos el caso de un Restaurante.

Escenario del Problema

"Queremos desarrollar un sistema simple para un restaurante. Necesitamos registrar los platillos del menú con su nombre y precio. Los clientes pueden realizar pedidos. El sistema debe poder calcular el total a pagar de un pedido agregando platillos dinámicamente."

Métricas de Análisis

Este gráfico muestra el balance de elementos identificados. Un buen análisis equilibra objetos (Sustantivos) y comportamientos (Verbos).

Del Plano a la Construcción (C#)

La Multiplicidad 1..*

¿Cómo se traduce "Muchos Platillos" al código? Usamos la colección List<T>.

private List<Platillo> _platillos;

El Método de Lógica

El método calcularTotal recorre la lista para sumar precios.

public decimal CalcularTotal() {
  return _platillos.Sum(p => p.Precio);
}
Pedido.cs C# compilable 
using System.Collections.Generic;

public class Pedido 
{
    // Atributos encapsulados
    public DateTime Fecha { get; set; }
    
    // Relación 1..* (Agregación)
    private List<Platillo> _items;

    public Pedido() 
    {
        _items = new List<Platillo>();
    }

    // Método del Diagrama
    public void Agregar(Platillo p) 
    {
        _items.Add(p);
    }
}
