Práctica de Laboratorio

☕ El Simulador de la Cafetería

Desarrolla una aplicación en consola utilizando Programación Orientada a Objetos en C#. En esta práctica trabajarás con clases, objetos, atributos, constructores y métodos para modelar bebidas de una cafetería.

01 · Objetivo

🎯 Objetivo

Crear un sistema básico que permita registrar bebidas, aplicar descuentos y simular su preparación utilizando conceptos fundamentales de POO.

02 · Contexto

📌 Contexto

Una cafetería necesita un sistema sencillo para registrar bebidas y mostrar información sobre cada una. Cada bebida tendrá:

  • Nombre
  • Tamaño
  • Precio
03 · Requerimientos

🧩 Requerimientos

  • Crear una clase llamada Bebida.
  • La clase debe contener atributos privados: nombre, tamaño y precio.
  • Crear un constructor que permita inicializar todos los atributos.
  • Crear un método Preparar() que muestre un mensaje en consola.
  • Crear un método AplicarDescuento(double porcentaje) para modificar el precio de la bebida.
  • Crear un método MostrarDescripcion() que muestre:
"Esto es un [nombre] de tamaño [tamaño]
con un costo de [precio]"
04 · Desarrollo

💻 Desarrollo en Main

  • Solicitar al usuario los datos de 3 bebidas.
  • Crear 3 objetos diferentes.
  • Aplicar descuento a una bebida.
  • Llamar al método Preparar() de todas.
  • Mostrar la descripción de cada bebida.

🖥️ Ejemplo Esperado

Preparando un Latte tamaño Grande...

Esto es un Latte de tamaño Grande
con un costo de $85

Preparando un Capuccino tamaño Mediano...

Esto es un Capuccino de tamaño Mediano
con un costo de $70
05 · Restricciones

🚫 Restricciones

⛔
No utilizar:
  • Herencia
  • Listas
  • Interfaces
  • Bases de datos
