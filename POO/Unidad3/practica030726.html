Propósito de la Práctica

Bienvenido a la práctica integradora. Aquí aplicarás el paradigma de programación orientada a objetos en C# para dar continuidad a un proyecto de software de escritorio preexistente (Windows Forms).

🎯 Objetivos Clave

  • ✓ Integrar persistencia de datos con MySQL.
  • ✓ Estructurar una arquitectura limpia (separación de responsabilidades).
  • ✓ Garantizar la seguridad usando consultas SQL parametrizadas.
  • ✓ Implementar control preventivo de excepciones.

🕐 Detalles

  • Unidades: U3 (Gestión de Datos) y U4 (Diseño).
  • Tiempo Estimado: 2 Horas de laboratorio + extra-clase.
  • Modalidad: Individual.

Paso 1 y 2: Preparación del Entorno

1. Clonar el Proyecto Base

Clona el repositorio oficial provisto por el docente. El proyecto contiene las ventanas de diseño (Login y Productos) pero está vacío a nivel lógico.

https://github.com/LMendoza70/Punto

2. Instalar el Conector MySQL

Para conectar tu aplicación de C# con MySQL, debes instalar el controlador oficial mediante NuGet.

  1. Da clic derecho sobre tu proyecto en el Explorador de Soluciones y selecciona Administrar paquetes NuGet...
  2. En la pestaña "Examinar", busca MySql.Data (de Oracle) o MySqlConnector.
  3. Instala la versión estable más reciente.

Paso 3: Creación de la Base de Datos

Ejecuta el siguiente script en tu gestor (Workbench, phpMyAdmin, etc.). El diseño coincide con los controles de tu formulario.

-- 1. Creación de la base de datos
CREATE DATABASE IF NOT EXISTS PuntoDB;
USE PuntoDB;

-- 2. Tabla para almacenar credenciales de acceso (Login)
CREATE TABLE IF NOT EXISTS usuarios (
    usuario_id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    password VARCHAR(100) NOT NULL, 
    nombre_completo VARCHAR(100) NOT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- 3. Tabla para el catálogo del CRUD (Productos)
CREATE TABLE IF NOT EXISTS productos (
    producto_id INT AUTO_INCREMENT PRIMARY KEY,
    codigo VARCHAR(50) NOT NULL UNIQUE,
    descripcion VARCHAR(150) NOT NULL,
    precio DECIMAL(10,2) NOT NULL,
    stock INT NOT NULL,
    CONSTRAINT chk_precio CHECK (precio >= 0),
    CONSTRAINT chk_stock CHECK (stock >= 0)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- 4. Registro inicial para validar el acceso al Login
INSERT INTO usuarios (username, password, nombre_completo) 
VALUES ('admin', 'admin123', 'Administrador del Sistema')
ON DUPLICATE KEY UPDATE username=username;

-- 5. Registros semilla para poblar el DataGridView inicial
INSERT INTO productos (codigo, descripcion, precio, stock) 
VALUES 
('75010011', 'Refresco de Cola 600ml', 18.50, 50),
('75010022', 'Papas Fritas Crujientes 45g', 16.00, 30)
ON DUPLICATE KEY UPDATE codigo=codigo;
