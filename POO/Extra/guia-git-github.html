¿Por qué dominar Git y GitHub?

Esta sección introduce la importancia fundamental del control de versiones en el desarrollo de software moderno, basándose en encuestas de la industria, y establece los cimientos para entender por qué estas herramientas son un estándar.

El Estándar de la Industria

Trabajar con nuestro código de forma segura es tan importante como aprender a programar. Herramientas como Git y GitHub son esenciales en el mundo del desarrollo de software.

  • ✓ Histórico seguro: Registra cada cambio en tu código.
  • ✓ Trabajo en equipo: Permite colaboración rápida y sin conflictos.
  • ✓ Visibilidad: Colaborar en código abierto mejora tu perfil profesional (tu "currículum verde").
"Sinceramente no existe una tecnología que se utilice tanto como Git en el mundo del desarrollo de software, sin importar el lenguaje de programación."

Adopción de Git según Stack Overflow

Porcentaje de desarrolladores que utilizan Git como sistema principal de control de versiones.

Preparando el Terreno

Aquí encontrarás los pasos esenciales para instalar el motor (Git) en tu máquina local y crear tu identidad en la nube (GitHub). Es el primer paso hacia el código colaborativo.

💻 1. Instalación de Git

  1. Descarga el instalador: Ve al sitio oficial git-scm.com.
  2. Ejecuta el asistente: Abre el archivo descargado.

    Recomendación: Deja las opciones por defecto. Asegúrate de marcar "Git Bash Here".

  3. Verificación: Abre una terminal (CMD o PowerShell) y escribe:
    $ git --version

    Si aparece un número (ej. git version 2.x.x), fue un éxito.

  4. Configuración Inicial: Identifícate para dar autoría a tus cambios:
    $ git config --global user.name "Tu Nombre"
    $ git config --global user.email "tu-email@ejemplo.com"

☁️ 2. Tu Cuenta en GitHub

GitHub es la plataforma donde alojarás tus repositorios remotos para colaborar o tener copias de seguridad.

1

Registro

Ingresa a github.com y haz clic en Sign up.

2

Tus Datos

Introduce correo, crea contraseña y elige un nombre de usuario único.

3

Verificación

Confirma el correo desde tu bandeja de entrada.

Nota: Puedes saltar las encuestas iniciales. Tu "perfil de desarrollador" está listo.

Conectando las Piezas en Visual Studio

Detalla cómo vincular tu entorno local (Git) y tu cuenta en la nube (GitHub) directamente dentro de Visual Studio para no tener que usar la terminal constantemente.

⚠️ Nota: Orientado a Visual Studio (2019/2022). Similar en VS Code vía extensiones.
👤

1. Iniciar Sesión

En la esquina superior derecha, haz clic en el icono de perfil o ve a Archivo > Cuenta de Microsoft. Inicia sesión vinculando tus credenciales de GitHub.

⚙️

2. Configuración

Ve a Herramientas > Opciones. Busca Control de código fuente > Configuración de repositorio de Git. Verifica que nombre y correo coincidan con los de Git local.

🎛️

3. El Panel de Control

Ve a Ver > Cambios de Git. Este panel lateral será tu centro de operaciones diario para manejar versiones y subir código a la nube.

Creando tu primer Repositorio (Paso A)

Para publicar un proyecto nuevo desde cero dentro del IDE:

  • 1. Clic en "Crear repositorio de Git" (barra inferior).
  • 2. Selecciona "GitHub" en la ventana emergente.
  • 3. Elige cuenta, nombra el repo y elige Privado/Público.
  • 4. Clic en "Crear e insertar". ¡Código en la nube!

💡 Sugerencias de Buenas Prácticas

Archivo README.md La carta de presentación del proyecto. Explica de qué trata y cómo ejecutarlo en local.
Archivo .gitignore Creado por VS automáticamente. Evita subir archivos innecesarios (como carpetas temporales `bin/` o `obj/`).
Mensajes de Commit Claros Evita "cambios" o "fix". Usa descripciones directas: "Corregido error en cálculo de impuestos".
