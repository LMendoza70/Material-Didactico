Diseño de Base de Datos

Estructura de las tablas y su relación en MySQL. Usamos un script SQL para crearlas.

table: grupos MySQL
Campo Tipo Atributos
🔑 id_grupo INT PK, AUTO_INC
nombre_grupo VARCHAR(50) NOT NULL
table: alumnos MySQL
Campo Tipo Atributos
🔑 matricula VARCHAR(20) PK
nombre VARCHAR(100) NOT NULL
🔗 id_grupo INT FK -> grupos
script.sql
CREATE TABLE grupos (
  id_grupo INT AUTO_INCREMENT PRIMARY KEY,
  nombre_grupo VARCHAR(50) NOT NULL
);

CREATE TABLE alumnos (
  matricula VARCHAR(20) PRIMARY KEY,
  nombre VARCHAR(100) NOT NULL,
  id_grupo INT,
  FOREIGN KEY (id_grupo) 
    REFERENCES grupos(id_grupo)
);

INSERT INTO grupos (nombre_grupo) 
VALUES ('1A Mañanas');

INSERT INTO alumnos (matricula, nombre, id_grupo) 
VALUES ('2026001', 'Ana García', 1);
🔗 Relación 1 a Muchos:

Un grupo puede tener muchos alumnos. La FOREIGN KEY (Llave Foránea) en la tabla alumnos asegura que no se asigne un alumno a un grupo que no existe.

💡 Tip de Seguridad:

Nunca subas tus contraseñas de BD a GitHub. Usa el archivo .env y agrégalo al .gitignore.

Despliegue Serverless

Publica tu API en Vercel para que el mundo pueda acceder a ella.

1

Configura vercel.json

Crea este archivo en la raíz para decirle a Vercel cómo ejecutar Node.js.

{ "builds": [{ "src": "src/app.js", "use": "@vercel/node" }] }
2

Variables de Entorno en Vercel

Crucial: Ve a Settings > Environment Variables en el dashboard de Vercel.

  • DB_HOST (De tu proveedor en la nube: Aiven, TiDB)
  • DB_USER
  • DB_PASSWORD

Adaptar app.js
