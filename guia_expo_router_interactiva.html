Introducción a Expo Router

Expo Router es un sistema de enrutamiento basado en archivos para React Native, inspirado en Next.js. Proporciona navegación nativa y configuración automática de rutas basada en la estructura de carpetas del proyecto.

📁

Basado en archivos

Las rutas se crean automáticamente según la estructura de carpetas

⚡

TypeScript nativo

Soporte completo para TypeScript con tipos seguros

🔗

Deep linking

URLs universales para web, iOS y Android

🎯

Navegación nativa

Usa las APIs nativas de navegación de cada plataforma

¿Por qué usar Expo Router?

✨ Simplicidad

No necesitas configurar navegadores manualmente. Solo crea archivos y carpetas.

🔒 Type-safe

TypeScript conoce todas tus rutas y parámetros automáticamente.

📱 Universal

El mismo código funciona en iOS, Android y Web sin cambios.

⚙️ Flexible

Soporta Stack, Tabs, Drawer y navegación anidada compleja.

Configuración inicial

Comenzamos desde una plantilla blank-typescript de Expo. Sigue estos pasos para configurar Expo Router.

Instalar dependencias

Instala todos los paquetes necesarios para Expo Router:

npx expo install expo-router react-native-safe-area-context react-native-screens expo-linking expo-constants expo-status-bar

Configurar app.json

Agrega la configuración del scheme en tu archivo app.json:

{
  "expo": {
    "scheme": "myapp",
    "web": {
      "bundler": "metro"
    }
  }
}

Crear estructura de archivos

Crea la carpeta app/ en la raíz del proyecto:

mi-proyecto/
├── app/
│   ├── _layout.tsx
│   ├── index.tsx
│   ├── (tabs)/
│   ├── (stack)/
│   └── (drawer)/
├── components/
├── app.json
└── package.json

Crear layout principal

El archivo app/_layout.tsx es el punto de entrada:

import { Stack } from 'expo-router';

export default function RootLayout() {
  return (
    <Stack>
      <Stack.Screen name="index" 
        options={{ headerTitle: 'Inicio' }} />
    </Stack>
  );
}

💡 Nota importante: Los nombres de carpetas entre paréntesis como (tabs) o (stack) son "grupos de rutas" que no aparecen en la URL. Esto permite organizar tu código sin afectar las rutas.

Navegación básica con Link

El componente Link es la forma más simple de navegar entre pantallas. Es declarativo y optimizado para React Native.

Ejemplo básico

import { Link } from 'expo-router';
import { View, Text, Button } from 'react-native';

export default function Home() {
  return (
    <View>
      <Text>Pantalla Principal</Text>
      
      <Link href="/about" asChild>
        <Button title="Ir a Acerca de" />
      </Link>
    </View>
  );
}

Propiedades importantes

Propiedad Descripción Ejemplo
href Ruta de destino href="/about"
asChild Usa el componente hijo como elemento clickeable asChild
replace Reemplaza la pantalla actual (no se puede volver atrás) replace

💡 Consejo: Usa asChild cuando quieras aplicar el Link a un componente personalizado o un Button. Sin asChild, Link renderiza un elemento táctil básico.

Navegación Stack

La navegación Stack apila pantallas una sobre otra, permitiendo al usuario navegar hacia adelante y atrás con animaciones nativas.

Configuración

// app/(stack)/_layout.tsx
import { Stack } from 'expo-router';

export default function StackLayout() {
  return (
    <Stack>
      <Stack.Screen 
        name="details" 
        options={{ 
          headerTitle: 'Detalles',
          headerBackTitle: 'Atrás'
        }} 
      />
      <Stack.Screen 
        name="[id]" 
        options={{ 
          presentation: 'modal'
        }}
      />
    </Stack>
  );
}

Navegación imperativa con useRouter

import { useRouter } from 'expo-router';

export default function Details() {
  const router = useRouter();
  
  const navigateToProduct = (id: number) => {
    router.push({
      pathname: "/(stack)/[id]",
      params: { id: id.toString() }
    });
  };

  return (
    <View>
      <Button 
        title="Ver Producto 1" 
        onPress={() => navigateToProduct(1)} 
      />
    </View>
  );
}

Métodos de useRouter

router.push()

Navega a una nueva pantalla. Agrega la pantalla al historial. 

router.push('/details')

router.replace()

Reemplaza la pantalla actual. No se puede volver atrás. 

router.replace('/home')

router.back()

Vuelve a la pantalla anterior en el stack. 

router.back()

router.canGoBack()

Verifica si hay una pantalla anterior disponible. 

router.canGoBack()

Opciones de presentación

Opción Descripción
presentation: 'card' Presentación normal (por defecto)
presentation: 'modal' Se presenta como modal desde abajo
presentation: 'transparentModal' Modal transparente sobre la pantalla anterior

Navegación por Tabs

Las tabs permiten cambiar rápidamente entre diferentes secciones de tu app. Son perfectas para las pantallas principales.

Configuración con íconos

// app/(tabs)/_layout.tsx
import { Tabs } from 'expo-router';
import { Ionicons } from '@expo/vector-icons';

export default function TabLayout() {
  return (
    <Tabs screenOptions={{
      tabBarActiveTintColor: '#3498db',
      tabBarInactiveTintColor: 'gray',
    }}>
      <Tabs.Screen
        name="home"
        options={{
          tabBarLabel: 'Inicio',
          tabBarIcon: ({ color, size }) => (
            <Ionicons name="home" size={size} color={color} />
          ),
        }}
      />
      <Tabs.Screen
        name="profile"
        options={{
          tabBarLabel: 'Perfil',
          tabBarIcon: ({ color, size }) => (
            <Ionicons name="person" size={size} color={color} />
          ),
        }}
      />
    </Tabs>
  );
}

Navegación Drawer

El Drawer crea un menú lateral deslizable, ideal para navegación secundaria o configuraciones.

Instalación adicional

npx expo install @react-navigation/drawer react-native-gesture-handler react-native-reanimated

⚠️ Importante: Después de instalar, debes configurar el plugin de reanimated en babel.config.js

Configuración de Babel

// babel.config.js
module.exports = function(api) {
  api.cache(true);
  return {
    presets: ['babel-preset-expo'],
    plugins: [
      'expo-router/babel',
      'react-native-reanimated/plugin', // ← Agregar esta línea
    ],
  };
};

Configuración del Drawer

Paso de parámetros entre pantallas

Expo Router permite pasar datos entre pantallas usando parámetros de URL. Puedes crear rutas dinámicas y acceder a los parámetros de forma type-safe.

1. Rutas dinámicas

Crea archivos con corchetes para definir rutas dinámicas: 

app/
├── (stack)/
│   ├── [id].tsx          → /stack/123, /stack/abc
│   ├── user/
│   │   └── [userId].tsx  → /stack/user/456
│   └── _layout.tsx

2. Pasar parámetros con Link

import { Link } from 'expo-router';

// Forma 1: Incluir parámetros en el href
<Link href={`/product/${productId}`}>
  Ver Producto
</Link>

// Forma 2: Objeto con pathname y params
<Link href={{
  pathname: "/product/[id]",
  params: { id: productId, color: 'blue' }
}}>
  Ver Producto
</Link>

3. Pasar parámetros con useRouter

import { useRouter } from 'expo-router';

export default function Products() {
  const router = useRouter();
  
  const viewProduct = (id: number) => {
    router.push({
      pathname: "/product/[id]",
      params: { 
        id: id.toString(),
        category: 'electronics',
        featured: 'true'
      }
    });
  };
  
  return (
    <Button 
      title="Ver Producto" 
      onPress={() => viewProduct(123)} 
    />
  );
}

4. Recibir parámetros con useLocalSearchParams

// app/product/[id].tsx
import { useLocalSearchParams } from 'expo-router';

interface ProductParams {
  id: string;
  category?: string;
  featured?: string;
}

export default function ProductScreen() {
  const params = useLocalSearchParams<ProductParams>();
  
  // Acceder a los parámetros
  console.log(params.id);        // "123"
  console.log(params.category);  // "electronics"
  console.log(params.featured);  // "true"
  
  return (
    <View>
      <Text>Producto ID: {params.id}</Text>
      <Text>Categoría: {params.category}</Text>
    </View>
  );
}

💡 Consejo TypeScript: Siempre define una interfaz para tus parámetros. Esto te da autocompletado y detección de errores en tiempo de desarrollo.

Tips y mejores prácticas

🎯 Organización de archivos

Usa grupos de rutas con paréntesis (tabs), (stack) para organizar tu código sin afectar las URLs. Esto hace tu proyecto más mantenible.

🔒 Type Safety

Siempre tipea tus parámetros con interfaces TypeScript. Usa useLocalSearchParams<T>() para obtener autocompletado y validación.

⚡ Navegación imperativa

Usa Link para navegación simple y useRouter cuando necesites lógica condicional o navegar desde funciones.

🎨 Consistencia

Mantén un estilo consistente de navegación en toda tu app. No mezcles demasiados patrones diferentes.

📱 Deep Linking

Todas tus rutas funcionan automáticamente como deep links. Configura el scheme en app.json para URLs personalizadas.

🔄 Redirecciones

Usa <Redirect href="/ruta" /> para redirecciones automáticas, útil para rutas protegidas o índices.

Patrones comunes

Autenticación y rutas protegidas

// app/_layout.tsx
import { Stack, Redirect } from 'expo-router';
import { useAuth } from '../context/auth';

export default function RootLayout() {
  const { user } = useAuth();
  
  if (!user) {
    return <Redirect href="/login" />;
  }
  
  return (
    <Stack>
      <Stack.Screen name="(app)" options={{ headerShown: false }} />
    </Stack>
  );
}

Navegación condicional

const router = useRouter();

const handleSubmit = async () => {
  const success = await saveData();
  
  if (success) {
    router.push('/success');
  } else {
    router.push('/error');
  }
};

Verificar si se puede volver atrás

const router = useRouter();

const handleBack = () => {
  if (router.canGoBack()) {
    router.back();
  } else {
    router.push('/'); // Ir al inicio si no hay historial
  }
};
